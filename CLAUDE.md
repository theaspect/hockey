# Игра для ребёнка (6 лет)

Родитель передаёт пожелания ребёнка — их нужно воплощать в игре.

## Как запускать
Открыть `index.html` двойным кликом в браузере. Без сборки, без сервера, без зависимостей.
Сайт: https://theaspect.github.io/hockey/ (GitHub Pages из ветки `master`, корень репо).
На iPad: открыть сайт в Safari → «Поделиться» → «На экран „Домой“» — работает как приложение и офлайн.
При добавлении/переименовании файлов — обновить список `FILES` в `sw.js` и поднять версию `CACHE`.
Иконки рисует `tools/make_icons.py` (чистый Python, без зависимостей).

## Репозиторий
Аккаунт GitHub `theaspect` (не рабочий!): автор коммитов `theaspect <theaspect@gmail.com>`,
ключ `~/.ssh/id_rsa.theaspect`, remote `git@theaspect:theaspect/hockey.git` — всё прописано в `.git/config`.
Для `gh` использовать `GH_TOKEN=$(gh auth token --user theaspect)`, активный аккаунт не переключать.

## Что за игра сейчас
Хоккей, ребёнок — **вратарь** (красный, левые ворота). Синий нападающий бросает по воротам.
Игра должна быть на **скилл**, а не на случайность (просьба родителя):
- ловля — только по кнопке (ловушка открыта 0.35 с), без нажатия шайба отскакивает от вратаря;
- бросок — по качающемуся прицелу-радару, зелёный = попадёт в ворота.
Очки: ⭐ = пойманный бросок соперника (+1); красный/синий кружки — голы (+1 каждый). Никаких бонусов.
Кроме скилла нужна **стратегия**: шайба отскакивает от бортов зеркально, прицел показывает путь с отскоками
(`tracePath` в `rink.js`), можно бросать через борт в обход нападающего. Нападающий караулит бросок вратаря
(патрулирует середину) и идёт на перехват (`interceptPoint`). На высоких уровнях компьютер тоже бьёт через борт.
Ворота стоят внутри площадки (`RINK.goalOffset`), за ними можно проехать; сетка твёрдая, гол — только
через створ спереди (`enteredThroughMouth`). Компьютер бьёт мимо вратаря (`aiShoot`, не идеально — `aimNoise`)
и на средних уровнях объезжает ворота сзади (`makeWrapRoute`). Зелёный прицел гарантирует попадание:
учтены торможение (`reachesEnd`), штанги (`clearsPosts`) и свои ворота как препятствие.

## Бэклог (пожелания, ещё не сделаны)
- **Смена ролей**: вратарь и нападающий меняются местами (ребёнок то ловит, то атакует).
- **2 игрока на планшете**: без клавиатуры нужен split-screen по тачу (левая половина — вратарь, правая — нападающий).
- Идеи «интересно и развивающе» (предложены родителю, ждут выбора):
  - голос-комментатор (speechSynthesis, ru-RU): «Гол! Три — один!» — учит числа на слух;
  - матч до N голов с кубком/медалью в конце — понятие цели и победы;
  - пенальти/тренировка: мишени в углах ворот, серия из 5 бросков — точность;
  - имя на форме: ребёнок сам набирает буквы своего имени — знакомство с буквами;
  - наклейки-достижения («5 сейвов подряд», «гол через борт») — мотивация;
  - повтор гола с нарисованной траекторией — угол падения = углу отражения;
  - тренер-подсказчик на «Легко»: стрелка, куда сейчас бросит компьютер — учит предвидеть.

## Git
Пользователь разрешил коммитить самому: после каждой доработки — отдельный коммит с описанием на русском,
что добавлено (с точки зрения игрока).
У ребёнка геймпад 8BitDo (Xbox-раскладка) — управление с геймпада обязательно.
Меню (☰ / Esc / Start): «Продолжить», «1 игрок» (против компьютера), «2 игрока» (нападающий — второй
игрок с клавиатуры или мыши). Выбор режима = новая игра. Схема управления по режимам — в шапке `game.js`.
Сложность растёт с каждым очком (сейвом): функции `shotSpeed`, `skaterSpeed`, `aimSpread`, `aimTime`,
`fakeChance`, `radarSpeed` в `game.js` зависят от `level()`.
Уровни сложности (Легко/Средне/Трудно) — таблица `DIFFICULTIES` в `game.js`, выбор в меню, сохраняется
в localStorage.

## Устройство
- `index.html` — страница с одним `<canvas>`.
- `js/input.js` — объект `Input`: клавиши, мышь/тач, геймпад. Кнопки геймпада — коды `PadA`, `PadLeft`…
  в тех же `isDown`/`wasPressed`; `Input.direction()` — общий вектор движения (стрелки+крестовина+стик).
- `js/sound.js` — `Sound.tone(...)`, `Sound.melody(...)`, звуки генерируются кодом.
- `js/rink.js` — размеры площадки (`WORLD`, `RINK`), отскоки от бортов, рисование площадки.
- `js/effects.js` — конфетти.
- `js/game.js` — логика, ИИ нападающего, рисование игроков, главный цикл.
- Скрипты подключаются обычными `<script>` (не ES-модули), чтобы работало с `file://`.
  Новые файлы — добавлять в `index.html` перед `game.js`.

## Правила для игры
- Игрок не читает: минимум текста, крупные яркие объекты, понятные картинки/эмодзи.
- Управление простое: стрелки или тап/клик мышью.
- Никаких проигрышей «насовсем» и страшного — мягкие последствия, много радости и звуков.
- Графика рисуется кодом или эмодзи, без внешних файлов, пока не понадобятся.
